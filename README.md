# QQViewerPin

> A tiny Windows tray utility that keeps QQ's image/video preview window at its last position, with adjustable opacity. No injection, no changes to QQ files.

让 QQ 聊天里的图片/视频预览窗固定在上次关闭的位置和大小，并支持半透明显示。

Windows 10/11 · 单文件 · 免安装 · 不修改 QQ

> 非腾讯官方项目，与腾讯无关。只在 QQ 9.9.36（Windows NTQQ）上测试过；QQ 更新后可能需要适配。

## 功能

- 双击聊天里的图片或视频，QQ 仍打开它自己的预览窗，工具自动接管：
  - 位置、大小继承上次关闭时的状态；
  - 图片和视频各记一份位置/大小；
  - 半透明显示，透明度全局共用；
  - 打开新图时旧预览窗自动关闭；
  - 默认隐藏任务栏/Alt+Tab 条目。
- 透明度和位置都只是“窗口级”调整，不修改图片内容。
- 快速隐藏当前预览窗：全局快捷键最小化/还原。
- 一键关闭所有预览窗：透明度很低时不用再找右上角关闭按钮。
- 快捷键可在托盘菜单里手动录制；冲突时弹窗提示，不会静默失效。
- 多显示器：按上次保存的屏幕位置打开；那块屏不在了就夹到最近的屏幕。
- 托盘菜单：透明度、暂停接管、设置快速隐藏快捷键、设置关闭快捷键、关闭所有预览窗、开机自启（默认关）、重置位置、退出。

预览窗保持普通窗口层级，**不会强制置顶**。

## 下载与安装

1. 到本仓库的 **Releases** 页面下载最新的 `QQViewerPin-v1.zip`；
2. 复制到桌面或 `C:\Tools` 等普通文件夹，**解压后**运行 `QQViewerPin.exe`；
3. 首次启动会创建 `%APPDATA%\QQViewerPin\config.json`。

需要 .NET Framework 4.8（Windows 10/11 自带，无需另外安装）。

> 不要把 exe 放在被系统标记为低完整性/沙箱的目录里运行，否则 Windows 会以低权限启动它，托盘图标、配置写入和 QQ 窗口操作都会失效。程序检测到低权限时会弹窗提醒并退出。
>
> 如果托盘里看不到图标，点任务栏右下角的 `^` 展开隐藏图标，或在“任务栏设置 → 其他系统托盘图标”里打开。

## 使用

1. 运行后，在 QQ 聊天里双击一张图片：预览窗会出现在**鼠标所在屏幕的右下角**（第一次没有历史位置时）。
2. 拖动、缩放窗口，按 `Alt+滚轮` 调整透明度，然后关闭。
3. 再双击另一张图片：新窗口会直接继承上次的位置、大小和透明度。
4. 右键托盘图标可以暂停接管、改快捷键或退出。

### 快捷键

| 操作 | 默认 | 说明 |
| --- | --- | --- |
| 快速隐藏/还原当前预览窗 | ``Alt+` `` | 被占用时自动回退 ``Ctrl+` ``；托盘菜单可改 |
| 调整透明度 | `Alt+滚轮` | 10%–100%，每格 5% |
| 关闭所有预览窗 | `Ctrl+Alt+W` | 被占用时回退 `Ctrl+Shift+W` / `Alt+Shift+W`；托盘菜单可改 |

所有快捷键都可以在托盘菜单里重新录制；设置时如果组合已被其他程序占用，会弹窗提示并停留在设置窗口，方便直接换一个。

## 配置

- 配置：`%APPDATA%\QQViewerPin\config.json`
- 日志：`%APPDATA%\QQViewerPin\log.txt`
- 如果配置目录不可写，日志会回退到 `%TEMP%\QQViewerPin.log`

删除整个 `%APPDATA%\QQViewerPin` 目录即可恢复默认设置；卸载时退出托盘程序并删除程序文件夹即可。

## 常见问题

**托盘里没有图标？**
点任务栏右下角的 `^` 展开隐藏图标；Windows 11 默认会把新图标收进去。也可以在“任务栏设置 → 其他系统托盘图标”里把它设为显示。

**打开图片没有移动 / 没有变透明？**
- 确认程序是在普通目录运行的（不是沙箱/低权限目录），且没有弹过低权限提示；
- 如果 QQ 以管理员权限运行，本工具也需要以管理员权限运行；
- 查看 `%APPDATA%\QQViewerPin\log.txt`，里面会记录接管和错误信息；
- 把 QQ 版本、Windows 版本和日志提 issue。

**快捷键冲突？**
设置窗口会弹“快捷键冲突”并给出错误码；换一个组合即可。启动时如果保存的快捷键被占用，托盘会弹警告，菜单里会显示“当前 冲突”。

**打开瞬间还会闪一下？**
当前版本会在窗口创建/标题就绪阶段先设置透明样式，再在显示阶段补一次。如果仍能稳定复现，请附上日志和 QQ 版本。

**QQ 更新后失效？**
QQ 可能改动预览窗的标题、类名或窗口结构。带日志提 issue，通常只需要更新识别规则。

## 兼容性

- Windows 10 / 11（x64）
- 已在 QQ 9.9.36（Windows NTQQ）上测试
- 只处理 QQ 聊天窗口打开的「图片查看器」和「视频播放器」窗口，不处理 QQ 其它窗口
- 需要和 QQ 相同的权限级别运行

## 工作原理与隐私

- 用 Win32 `SetWinEventHook` 监听预览窗的创建、标题变化、显示和移动；
- 用 `SetWindowPos`、`SetLayeredWindowAttributes` 调整窗口位置、大小和透明度；
- 用 `WM_CLOSE` 关闭旧预览窗或全部预览窗；
- **不注入 QQ 进程、不修改 QQ 安装文件、不读取聊天内容、不联网**；
- 只读取窗口标题、窗口类名和进程路径，配置只写本地。

程序没有代码签名，Windows SmartScreen 可能提示；源码在仓库里，可以自行审阅或用 `build.cmd` 构建。

## 从源码构建

要求：Windows + .NET Framework 4.8（系统自带 `csc.exe`）。

```bat
build.cmd
```

生成 `QQViewerPin.exe`。`build.cmd` 使用系统自带的 C# 5 编译器，不依赖 Visual Studio 或 NuGet。

`test/` 下有一套用模拟窗口做的自动化测试，可在没有 QQ 的环境下验证位置继承、透明度、旧窗关闭和关闭全部等逻辑；测试脚本需要 Windows PowerShell 5.1。
